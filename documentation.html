02 Basic Usage

Learn the fundamentals of bookmark.py

Adding Bookmarks

Navigate to any directory and add it as a bookmark with a simple command:

bash 
cd ~/projects/my-awesome-project
bookmark

Listing Bookmarks

View all your saved bookmarks with their paths:

bash 
$ bookmark --list
1. awesome → /Users/username/projects/my-awesome-project
2. config → /Users/username/.config
3. downloads → /Users/username/Downloads

Navigating to Bookmarks

Jump to any bookmarked directory instantly:

bash 
$ bookmark --go awesome
📁 Jumped to: /Users/username/projects/my-awesome-project

Quick Navigation

Use numbers for even faster navigation:

bash 
$ bookmark --go 1
📁 Jumped to: /Users/username/projects/my-awesome-project

04 Configuration

Customize bookmark.py to your workflow

Configuration File

bookmark.py stores configuration in ~/.bookmarkrc:

ini 
[display]
show_numbers = true
max_path_length = 50

[aliases]
proj = "bookmark --go project"
docs = "bookmark --go documentation"

[colors]
enabled = true
primary = green
accent = blue

Configuration Options

show_numbers

boolean

Show bookmark numbers in list output

true (default) • false

max_path_length

integer

Maximum characters to show for paths

50 (default) • any number

auto_save

boolean

Automatically save bookmarks after changes

true (default) • false

06 Troubleshooting

Common issues and solutions

Command not found: bookmark

+

This usually means bookmark.py isn't in your PATH. Try these solutions:

# Check if bookmark.py is in your PATH
which bookmark

# If not found, add it to your shell config
echo 'export PATH="$PATH:/path/to/bookmark.py"' >> ~/.zshrc
source ~/.zshrc

Bookmarks not persisting

+

Check file permissions for the bookmark storage:

# Check bookmark file permissions
ls -la ~/.bookmark.py

# Fix permissions if needed
chmod 644 ~/.bookmark.py

Shell completion not working

+

Enable shell completion by adding this to your shell config:

# For Zsh
echo 'source ~/.bookmark.py/completion.zsh' >> ~/.zshrc

# For Bash
echo 'source ~/.bookmark.py/completion.bash' >> ~/.bashrc
